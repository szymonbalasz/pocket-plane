# Compendium expansion (post-MVP stub)

- **What:** third-party JSON import (a separate project, tier C): the DM supplies their own files at run time; nothing non-SRD is bundled or committed; more content types (spells, items, classes, backgrounds…); richer homebrew authoring.
- **Builds on:** [compendium](compendium.md), [fixtures-adapters](../fixtures-adapters.md), [ADR-0010](../../architecture/adr/0010-compendium-design.md).

  - Dedupe across sources (same goblin from Open5e and 5etools).
